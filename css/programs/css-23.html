Float & Clear

Use float to position content and clear to stop wrapping.

Demonstration

FLOAT

Text wraps around the floated box. This demonstrates float layout behavior.

clear: both

Content after the clear starts below the float.

Code

.float-box{float:left;width:150px;height:100px;margin:0 20px 10px 0;padding:30px;background:#dbeafe;text-align:center;font-weight:bold}.clear-box{clear:both;padding:12px;background:#dcfce7}
