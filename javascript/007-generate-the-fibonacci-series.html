Generate the fibonacci series

Question: Write a JavaScript program to generate the fibonacci series.
▶ Live Output
Working example
JavaScript Code
let n = 10;
    let a = 0;
    let b = 1;
    let series = [];

    for (let i = 0; i < n; i++) {
        series.push(a);

        let next = a + b;
        a = b;
        b = next;
    }

    document.getElementById("result").textContent =
        "Fibonacci Series: " + series.join(", ");
