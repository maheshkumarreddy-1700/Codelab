Find the sum and average of array elements

Question: Write a JavaScript program to find the sum and average of array elements.
▶ Live Output
Working example
JavaScript Code
let marks = [80, 75, 90, 85, 70];

let sum = 0;

for (let mark of marks) {
    sum += mark;
}

let average = sum / marks.length;

document.getElementById("sum").textContent =
    "Sum = " + sum;

document.getElementById("average").textContent =
    "Average = " + average;
