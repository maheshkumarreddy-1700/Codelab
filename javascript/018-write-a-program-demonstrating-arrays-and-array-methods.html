Write a program demonstrating arrays and array methods

Question: Write a JavaScript program to write a program demonstrating arrays and array methods.
▶ Live Output
Working example
JavaScript Code
let islands = ["Taj", "Poompuhar", "Madurai"];

islands.push("Korkai");

document.getElementById("push").textContent =
    "After push: " + islands.join(", ");

let removed = islands.pop();

document.getElementById("pop").textContent =
    "Removed: " + removed;

document.getElementById("join").textContent =
    "Joined: " + islands.join(" - ");

let upper = islands.map(item => item.toUpperCase());

document.getElementById("map").textContent =
    "Map: " + upper.join(", ");
