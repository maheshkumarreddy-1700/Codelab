Write a program demonstrating date and math objects

Question: Write a JavaScript program to write a program demonstrating date and math objects.
▶ Live Output
Working example
JavaScript Code
let today = new Date();

document.getElementById("date").textContent =
    "Current Date: " + today.toLocaleDateString();

document.getElementById("random").textContent =
    "Random Number: " + Math.floor(Math.random() * 100);

document.getElementById("round").textContent =
    "Rounded Value: " + Math.round(45.67);

document.getElementById("sqrt").textContent =
    "Square Root of 81: " + Math.sqrt(81);
