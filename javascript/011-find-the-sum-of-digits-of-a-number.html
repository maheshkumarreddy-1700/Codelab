Find the sum of digits of a number

Question: Write a JavaScript program to find the sum of digits of a number.
▶ Live Output
Working example
JavaScript Code
let number = 12345;
let temp = number;
let sum = 0;

while (temp > 0) {
    sum += temp % 10;
    temp = Math.floor(temp / 10);
}

document.getElementById("result").textContent =
    "Sum of digits = " + sum;
