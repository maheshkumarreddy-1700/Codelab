Write a program demonstrating strings and string methods

Question: Write a JavaScript program to write a program demonstrating strings and string methods.
▶ Live Output
Working example
JavaScript Code
let text = "Taj Mahal";

document.getElementById("length").textContent =
    "Length: " + text.length;

document.getElementById("upper").textContent =
    "Uppercase: " + text.toUpperCase();

document.getElementById("lower").textContent =
    "Lowercase: " + text.toLowerCase();

document.getElementById("slice").textContent =
    "Slice: " + text.slice(0, 6);

document.getElementById("replace").textContent =
    "Replace: " + text.replace("Taj", "Ancient");
