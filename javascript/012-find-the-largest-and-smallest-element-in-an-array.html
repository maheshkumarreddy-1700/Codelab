Find the largest and smallest element in an array

Question: Write a JavaScript program to find the largest and smallest element in an array.
▶ Live Output
Working example
JavaScript Code
let numbers = [25, 8, 42, 15, 67, 12];

let largest = Math.max(...numbers);
let smallest = Math.min(...numbers);

document.getElementById("largest").textContent =
    "Largest: " + largest;

document.getElementById("smallest").textContent =
    "Smallest: " + smallest;
