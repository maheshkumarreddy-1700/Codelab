Program 1: Basic HTML: Headings, Paragraphs and Line Breaks

Demonstrates the basic structure of an HTML document and the use of heading, paragraph, and line-break elements.

Aim

To create a basic HTML webpage using headings, paragraphs, and line breaks.

Description

Demonstrates the basic structure of an HTML document and the use of heading, paragraph, and line-break elements.

Complete Source Code

program1.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Basic HTML</title>
</head>
<body>
    <h1>Welcome to My Webpage</h1>
    <h2>About HTML</h2>

    <p>HTML is used to structure content on webpages.</p>

    <p>
        This is the first line.<br>
        This is the second line.<br>
        This is the third line.
    </p>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Headings organize content into levels. The <p> element creates paragraphs, while <br> moves the following text to a new line without creating a new paragraph.

Key Concepts

HTML document structureHeading elementsParagraph elementLine break element <br>

Notes

Use heading levels in logical order. Avoid using repeated <br> tags for page spacing; CSS is better for layout.
