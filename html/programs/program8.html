Program 8: Semantic HTML Elements

Demonstrates meaningful page structure using HTML5 semantic elements instead of relying only on generic containers.

Aim

To create an HTML page demonstrating semantic elements such as <header>, <nav>, <section>, <article>, and <footer>.

Description

Demonstrates meaningful page structure using HTML5 semantic elements instead of relying only on generic containers.

Complete Source Code

program8.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Semantic HTML</title>
</head>

<body>
    <header>
        <h1>My College Website</h1>
    </header>

    <nav>
        <a href="#">Home</a> |
        <a href="#">Courses</a> |
        <a href="#">Contact</a>
    </nav>

    <section>
        <h2>Latest News</h2>

        <article>
            <h3>Web Development Workshop</h3>
            <p>
                Students can participate in the upcoming workshop.
            </p>
        </article>
    </section>

    <footer>
        <p>&copy; 2026 My College</p>
    </footer>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Semantic elements describe the role of content. <header> introduces a page or section, <nav> contains navigation, <section> groups related content, <article> represents independent content, and <footer> contains closing information.

Key Concepts

Notes

Semantic HTML improves structure, accessibility, and maintainability.
