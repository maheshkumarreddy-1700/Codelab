Program 10: College Timetable using HTML Table

Demonstrates how a timetable can be represented using table rows, headings, and cells.

Aim

To create a college timetable using an HTML table.

Description

Demonstrates how a timetable can be represented using table rows, headings, and cells.

Complete Source Code

program10.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>College Timetable</title>

    <style>
        table {
            border-collapse: collapse;
            width: 90%;
        }

        th, td {
            border: 1px solid #333;
            padding: 12px;
            text-align: center;
        }

        th {
            background: #e8e8e8;
        }
    </style>
</head>

<body>
    <h1>College Timetable</h1>

    <table>
        <tr>
            <th>Day</th>
            <th>9:00 - 10:00</th>
            <th>10:00 - 11:00</th>
            <th>11:00 - 12:00</th>
            <th>1:00 - 2:00</th>
        </tr>

        <tr>
            <th>Monday</th>
            <td>DS</td>
            <td>Math</td>
            <td>HTML</td>
            <td>EVS</td>
        </tr>

        <tr>
            <th>Tuesday</th>
            <td>Python</td>
            <td>CSS</td>
            <td>Math</td>
            <td>DS</td>
        </tr>

        <tr>
            <th>Wednesday</th>
            <td colspan="2">HTML Lab</td>
            <td>English</td>
            <td>Math</td>
        </tr>
    </table>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

A timetable is naturally represented using an HTML table. Rows represent days and columns represent time periods or subjects.

Key Concepts

Table layoutRowsColumnscolspanTable styling

Notes

Keep the timetable readable on small screens; a responsive wrapper can be added for mobile devices.
