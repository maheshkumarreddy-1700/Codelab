Program 2: Ordered, Unordered and Description Lists

Demonstrates three common HTML list types: ordered lists for sequences, unordered lists for bullet points, and description lists for terms and definitions.

Aim

To create an HTML page containing ordered, unordered, and description lists.

Description

Demonstrates three common HTML list types: ordered lists for sequences, unordered lists for bullet points, and description lists for terms and definitions.

Complete Source Code

program2.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Lists</title>
</head>
<body>
    <h1>HTML Lists</h1>

    <h2>Ordered List</h2>
    <ol>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
    </ol>

    <h2>Unordered List</h2>
    <ul>
        <li>Python</li>
        <li>C</li>
        <li>Java</li>
    </ul>

    <h2>Description List</h2>
    <dl>
        <dt>HTML</dt>
        <dd>Structures webpages.</dd>

        <dt>CSS</dt>
        <dd>Styles webpages.</dd>
    </dl>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

<ol> creates a numbered list, <ul> creates a bulleted list, and <dl> contains terms (<dt>) and their descriptions (<dd>).

Key Concepts

Ordered listUnordered listDescription listList items

Notes

Use ordered lists when sequence matters. Use unordered lists when order does not matter.
