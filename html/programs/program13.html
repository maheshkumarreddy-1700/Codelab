Program 13: Responsive Webpage using CSS Media Queries

Demonstrates how a page can adapt its styling for smaller screens using a CSS media query.

Aim

To create a responsive webpage using CSS media queries.

Description

Demonstrates how a page can adapt its styling for smaller screens using a CSS media query.

Complete Source Code

program13.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Responsive Webpage</title>

    <style>
        * {
            box-sizing: border-box;
        }

        body {
            margin: 0;
            font-family: Arial, sans-serif;
            background: #eef2ff;
        }

        .container {
            max-width: 900px;
            margin: auto;
            padding: 30px;
        }

        .card {
            background: white;
            padding: 40px;
            border-radius: 16px;
        }

        @media (max-width: 600px) {
            .container {
                padding: 15px;
            }

            .card {
                padding: 20px;
            }

            h1 {
                font-size: 28px;
            }
        }
    </style>
</head>

<body>
    <div class="container">
        <div class="card">
            <h1>Responsive Webpage</h1>
            <p>
                Resize the browser window to see the media query
                change the page styling.
            </p>
        </div>
    </div>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

A media query applies CSS rules only when its condition is true. Here, the page reduces spacing and heading size when the viewport is 600px wide or less.

Key Concepts

Responsive design@mediamax-widthViewportMobile layout

Notes

Always include the viewport meta tag when building responsive pages.
