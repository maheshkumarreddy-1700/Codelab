Program 4: Images and Hyperlinks

Demonstrates how to embed an image and create a hyperlink to another webpage.

Aim

To create an HTML page containing images and hyperlinks.

Description

Demonstrates how to embed an image and create a hyperlink to another webpage.

Complete Source Code

program4.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Images and Hyperlinks</title>
</head>

<body>
    <h1>Images and Hyperlinks</h1>

    <img
        src="https://via.placeholder.com/500x250"
        alt="Sample webpage image"
        width="500"
    >

    <p>
        <a href="https://www.google.com" target="_blank">
            Visit Google
        </a>
    </p>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

The <img> element displays an image. The src attribute specifies its location and alt provides alternative text. The <a> element creates a hyperlink.

Key Concepts

Imagessrc attributealt attributeHyperlinkshref attributetarget attribute

Notes

In a real project, store images locally when possible. Always provide useful alt text for important images.
