Program 6: Audio and Video Elements

Demonstrates HTML5 multimedia elements using audio and video controls.

Aim

To create a webpage using audio and video elements.

Description

Demonstrates HTML5 multimedia elements using audio and video controls.

Complete Source Code

program6.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Audio and Video</title>
</head>

<body>
    <h1>HTML5 Multimedia</h1>

    <h2>Audio</h2>
    <audio controls>
        <source src="audio.mp3" type="audio/mpeg">
        Your browser does not support audio.
    </audio>

    <h2>Video</h2>
    <video width="600" controls>
        <source src="video.mp4" type="video/mp4">
        Your browser does not support video.
    </video>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

<audio> embeds audio and <video> embeds video. The controls attribute gives users browser controls such as play, pause, and volume.

Key Concepts

HTML5 audioHTML5 videosource elementcontrols attributeFallback text

Notes

Place audio.mp3 and video.mp4 beside the HTML file when testing this example locally.
