Program 11: Internal and External CSS Styling

Demonstrates the use of a <style> block for internal CSS and a linked stylesheet for external CSS.

Aim

To create a webpage with internal and external CSS styling.

Description

Demonstrates the use of a <style> block for internal CSS and a linked stylesheet for external CSS.

Complete Source Code

program11.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Internal and External CSS</title>

    <link rel="stylesheet" href="style.css">

    <style>
        .internal {
            color: #7c5cff;
            padding: 15px;
            border: 2px solid #7c5cff;
        }
    </style>
</head>

<body>
    <h1 class="internal">This heading uses internal CSS</h1>

    <p class="external">
        This paragraph uses external CSS.
    </p>
</body>
</html>

/* style.css */
.external {
    color: #008fb3;
    font-size: 20px;
    font-weight: bold;
}

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Internal CSS is written inside a <style> element in the HTML document. External CSS is stored in a separate .css file and connected with <link>.

Key Concepts

Internal CSSExternal CSSstyle elementlink elementCSS classes

Notes

Create a file named style.css beside the HTML file and place the .external rule there when running the example as separate files.
