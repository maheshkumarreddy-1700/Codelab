Program 5: Student Registration Form

Demonstrates text fields, email input, radio buttons, a select menu, and a submit button.

Aim

To create a student registration form using HTML form elements.

Description

Demonstrates text fields, email input, radio buttons, a select menu, and a submit button.

Complete Source Code

program5.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Student Registration</title>
</head>

<body>
    <h1>Student Registration Form</h1>

    <form>
        <label for="name">Full Name:</label>
        <input type="text" id="name" name="name">
        <br><br>

        <label for="email">Email:</label>
        <input type="email" id="email" name="email">
        <br><br>

        <label>Gender:</label>
        <input type="radio" id="male" name="gender" value="male">
        <label for="male">Male</label>

        <input type="radio" id="female" name="gender" value="female">
        <label for="female">Female</label>
        <br><br>

        <label for="course">Course:</label>
        <select id="course" name="course">
            <option>B.Tech</option>
            <option>BCA</option>
            <option>B.Sc</option>
        </select>
        <br><br>

        <button type="submit">Register</button>
    </form>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

The <form> element groups user-input controls. Labels identify fields, input elements collect data, radio buttons allow one choice from a group, and select creates a dropdown.

Key Concepts

FormsLabelsInput elementsRadio buttonsSelect and optionSubmit button

Notes

Use labels for form controls. In a production form, also add validation and a server-side endpoint.
