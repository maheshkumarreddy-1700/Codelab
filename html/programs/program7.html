Program 7: Frames / Iframes

Demonstrates the modern HTML <iframe> element for embedding another document or webpage inside the current page.

Aim

To create a webpage using frames/iframes.

Description

Demonstrates the modern HTML <iframe> element for embedding another document or webpage inside the current page.

Complete Source Code

program7.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Iframe Example</title>
</head>

<body>
    <h1>Using an Iframe</h1>

    <iframe
        src="https://example.com"
        width="700"
        height="400"
        title="Example website">
    </iframe>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Older HTML framesets are obsolete. The modern approach is <iframe>, which embeds another HTML document within a webpage.

Key Concepts

iframesrcwidth and heighttitle attributeEmbedded documents

Notes

Some websites block iframe embedding for security reasons. For your lab, use a page that permits embedding or a local HTML file.
