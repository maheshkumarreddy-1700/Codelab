Program 14: Bootstrap Components

Demonstrates Bootstrap's CDN, alert, button, container and card components.

Aim

To create a webpage using Bootstrap components.

Description

Demonstrates Bootstrap's CDN, alert, button, container and card components.

Complete Source Code

program14.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Bootstrap Components</title>

    <link
        href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
        rel="stylesheet">
</head>

<body>
    <div class="container py-5">
        <h1 class="mb-4">Bootstrap Components</h1>

        <div class="alert alert-primary">
            Welcome to Bootstrap.
        </div>

        <button class="btn btn-success">
            Bootstrap Button
        </button>

        <div class="card mt-4" style="max-width: 400px;">
            <div class="card-body">
                <h5 class="card-title">Sample Card</h5>
                <p class="card-text">
                    This card uses Bootstrap classes.
                </p>
                <a href="#" class="btn btn-primary">
                    Learn More
                </a>
            </div>
        </div>
    </div>

    <script
        src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js">
    </script>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Bootstrap is a front-end framework that provides ready-made responsive styles and components. The CDN link loads Bootstrap so its classes can be used directly.

Key Concepts

Bootstrap CDNContainerAlertButtonCardBootstrap utility classes

Notes

An internet connection is required for the CDN version. For offline submission, download Bootstrap files and reference them locally.
