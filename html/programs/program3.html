Program 3: Tables with Rows, Columns, Borders and Merged Cells

Demonstrates table structure using rows and cells, together with colspan and rowspan for merged cells.

Aim

To create a webpage using tables with rows, columns, borders, and merged cells.

Description

Demonstrates table structure using rows and cells, together with colspan and rowspan for merged cells.

Complete Source Code

program3.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML Table</title>

    <style>
        table, th, td {
            border: 1px solid #333;
            border-collapse: collapse;
            padding: 10px;
        }
    </style>
</head>

<body>
    <h1>Student Details</h1>

    <table>
        <tr>
            <th colspan="3">Student Details</th>
        </tr>

        <tr>
            <th>Name</th>
            <th>Course</th>
            <th>Year</th>
        </tr>

        <tr>
            <td>Mahesh</td>
            <td>Computer Science</td>
            <td>1</td>
        </tr>

        <tr>
            <td rowspan="2">Student Group</td>
            <td>Web Development</td>
            <td>1</td>
        </tr>

        <tr>
            <td colspan="2">Practical Lab</td>
        </tr>
    </table>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

<table> creates the table, <tr> creates rows, <th> creates headings, and <td> creates data cells. colspan merges columns and rowspan merges rows.

Key Concepts

TablesRows and cellsTable headingscolspanrowspanBorders

Notes

Use tables for tabular data, not for general webpage layout. Keep table headings meaningful.
