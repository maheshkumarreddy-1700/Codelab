Program 12: CSS Selectors, Colors, Fonts, Margins, Padding and Borders

Demonstrates universal, element, class and ID selectors along with common CSS styling properties.

Aim

To create a webpage demonstrating CSS selectors, colors, fonts, margins, padding, and borders.

Description

Demonstrates universal, element, class and ID selectors along with common CSS styling properties.

Complete Source Code

program12.html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CSS Styling</title>

    <style>
        * {
            font-family: Arial, sans-serif;
        }

        body {
            background: #f2f2f2;
        }

        h1 {
            color: #6c4cff;
        }

        .box {
            margin: 30px;
            padding: 25px;
            border: 3px solid #222;
            background: white;
        }

        #special {
            color: #d33;
            font-weight: bold;
        }
    </style>
</head>

<body>
    <h1>CSS Selectors and Styling</h1>

    <div class="box">
        <p id="special">
            This paragraph demonstrates CSS styling.
        </p>
    </div>
</body>
</html>

Output / Preview

Live preview of the practical where browser security/resources allow it.

Explanation

Selectors decide which elements receive styles. Colors change visual appearance, fonts control typography, margin creates outer space, padding creates inner space, and borders surround an element.

Key Concepts

Universal selectorElement selectorClass selectorID selectorcolorfont-familymarginpaddingborder

Notes

Prefer classes for reusable styling. Use IDs when an element needs a unique identifier.
